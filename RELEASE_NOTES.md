Версия 1.1.0

Новое:
- Новый интерфейс на Qt: вставка Ctrl+V в любой раскладке, меню по правой кнопке, календарь для даты, перетаскивание счёта мышкой в окно
- Конструктор КП: блоки можно перетаскивать, скрывать и добавлять свои (текст, картинка, две колонки, разделитель, отступ) с живым предпросмотром
- Оформление текста приветствия и подписи: жирный, курсив, цвет, размер
- Значок WhatsApp после номеров телефонов
- Строка с реквизитами под «От: компания»
- Номер КП берётся из номера счёта; во вкладке «Из счёта» можно выбрать, что переносить из счёта
- Слово «теңге» в КП пишется по закону

Исправления:
- Счета из разных печатных форм 1С читаются универсально (другие заголовки колонок, порядок данных покупателя)
- Файл настроек больше не превращается в «папку» при пересылке; импорт принимает и .zip, и распакованную папку
- Печать прижимается к правому краю страницы
