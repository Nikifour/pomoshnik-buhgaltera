# Помощник Бухгалтера

Программа-помощник для бухгалтерии. Первый модуль — коммерческое предложение из счёта на оплату (выгрузка 1С в Excel).

## Установка
Скачайте со страницы релизов **`Pomoshnik-Buhgaltera-Setup.exe`** и запустите.
Права администратора не нужны: программа ставится в профиль пользователя
(`%LOCALAPPDATA%\Programs\Pomoshnik-Buhgaltera`), создаёт ярлыки на рабочем столе и в меню «Пуск»
и удаляется через «Параметры → Приложения».

Без установки: скачайте `Pomoshnik-Buhgaltera.exe` и положите в любую папку, куда можно писать
(не в `C:\Program Files` — иначе не сработает автообновление).

При первом запуске Windows может показать «Система Windows защитила ваш компьютер» —
нажмите «Подробнее» → «Выполнить в любом случае» (у программы нет платной цифровой подписи).

## Для пользователя
1. «Новое КП» → «Выбрать счёт на оплату» → проверить «Кому», № и дату КП.
2. «Сформировать КП» — файлы сохраняются в папку из настроек
   (по умолчанию `Документы\Коммерческие предложения`).

- **История** — все созданные КП с поиском, открытие в Excel / PDF.
- **Шаблон КП** — контакты, тексты, два логотипа, печать, цветовая схема,
  пароль на шаблон, резервные копии, перенос настроек.
- **Обновления** — программа сама проверяет GitHub при запуске и предлагает обновиться.

При первом запуске программа предлагает выбрать логотип и подбирает под него
цветовую схему — или импортировать готовые настройки из файла. Оба шага можно пропустить.

PDF создаётся через установленный Microsoft Excel.

## Настройка программы у сотрудников
1. Настройте шаблон у себя → «Шаблон КП» → «Прочее» → **«Экспорт настроек…»**.
   Программа спросит, включать ли печать и подпись.
2. Отправьте файл `.pbsettings` сотруднику.
3. Сотрудник открывает файл двойным щелчком (если программа установлена установщиком)
   или выбирает «Импорт настроек» в мастере первого запуска / в «Шаблон КП» → «Прочее».

Файл `.pbsettings` содержит данные компании — не публикуйте его. Если в нём печать и подпись,
передавайте его только тем, кому положено ставить печать.

## Данные компании не хранятся в репозитории
В коде нет контактов, реквизитов, логотипов, печатей и подписей — всё это
вводится в программе и лежит только в локальной папке `data` (она в `.gitignore`).
Сборка на GitHub дополнительно проверяет, что в репозиторий не попали картинки,
настройки или документы.

Папка `data` лежит рядом с .exe (или в `%APPDATA%\Помощник Бухгалтера`, если туда нельзя писать)
и сохраняется при обновлении и удалении программы (при удалении установщик спросит).

## Выпуск новой версии
1. Внести изменения, описать их в `RELEASE_NOTES.md`.
2. Закоммитить и поставить тег:
   ```
   git tag v1.0.1
   git push origin main v1.0.1
   ```
3. GitHub Actions соберёт `Pomoshnik-Buhgaltera.exe` и установщик `Pomoshnik-Buhgaltera-Setup.exe`
   и опубликует релиз — программы у пользователей предложат обновиться при следующем запуске.

## Структура
- `app.py` — точка входа
- `version.py` — версия и репозиторий для обновлений
- `core/` — логика без интерфейса
  - `invoice_parser.py` — чтение счёта (колонки ищутся по заголовкам)
  - `kp_builder.py` — макет КП (зашит в программу)
  - `settings_store.py` — редактируемые поля, резервные копии, нумерация
  - `profile_transfer.py` — экспорт/импорт настроек (`.pbsettings`)
  - `colors.py` — подбор цветовой схемы по логотипу
  - `updater.py` — автообновление из релизов GitHub с проверкой SHA-256
- `ui/` — интерфейс (customtkinter)
  - `main_window.py` — окно, меню, баннер обновления
  - `page_new.py`, `page_history.py`, `page_template.py` — страницы
  - `setup_dialog.py` — мастер первого запуска
  - `transfer_actions.py` — кнопки экспорта/импорта настроек
  - `theme.py`, `widgets.py` — цвета, шрифты, общие элементы
- `installer/setup.iss` — установщик (Inno Setup 6)
- `assets/` — только иконка программы

Новая страница = новый файл `ui/page_*.py` + строка в `MainWindow.pages` и в меню.

## Разработка
```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python app.py
build.bat              — собрать dist\Pomoshnik-Buhgaltera.exe
build_installer.bat    — собрать .exe и установщик (нужен Inno Setup 6)
```
