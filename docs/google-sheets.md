# Как подключить свою Google Таблицу для статистики КП

Программа может записывать каждое сформированное коммерческое предложение в Google Таблицу.
В таблице появится лист **«Сводка»** (сколько КП и на какую сумму — всего и за месяц, по каждому
сотруднику) и отдельный лист на каждого сотрудника с расшифровкой: дата, № КП, покупатель, сумма,
количество позиций.

Таблица хранится в **вашем** Google-аккаунте. Программа умеет только добавлять в неё строки —
читать ваш Google Диск или почту она не может.

> Если руководитель уже прислал вам файл настроек (`.pbsettings`) с подключённой статистикой —
> ничего делать не нужно: просто импортируйте его и впишите своё имя при запуске программы.

---

## Что понадобится
- Google-аккаунт (обычный Gmail подходит).
- 10 минут.

## Шаг 1. Создайте таблицу
1. Откройте [sheets.new](https://sheets.new) — создастся новая пустая таблица.
2. Назовите её, например, **«Статистика КП»** (щёлкните по названию «Новая таблица» вверху слева).
3. Скопируйте адрес таблицы из адресной строки браузера — он выглядит так:
   `https://docs.google.com/spreadsheets/d/…длинный код…/edit`

## Шаг 2. Подготовьте код в программе
1. В программе: **⚙ Настройки → Шаблон КП → вкладка «Статистика»**.
2. Вставьте адрес таблицы в поле **«Ссылка на таблицу»**.
3. Нажмите **«Создать ключ»** — появится секретный ключ. Никому его не пересылайте отдельно.
4. Нажмите **«Скопировать код скрипта»** — код с вашим ключом и адресом таблицы окажется
   в буфере обмена.

## Шаг 3. Вставьте код в таблицу
1. В таблице откройте меню **Расширения → Apps Script**. Откроется редактор скриптов.
2. Щёлкните в поле с кодом, нажмите **Ctrl+A**, затем **Ctrl+V** — пример заменится нашим кодом.
3. Нажмите **Ctrl+S** (сохранить). Вверху можно переименовать проект, например в «Статистика КП».

## Шаг 4. Опубликуйте скрипт как веб-приложение
1. Нажмите синюю кнопку **«Начать развертывание» → «Новое развертывание»**.
2. Слева у «Выберите тип» нажмите шестерёнку и выберите **«Веб-приложение»**.
3. Заполните:
   - **Описание** — любое, например «Статистика КП»;
   - **Запуск от имени** — **«От моего имени»**;
   - **У кого есть доступ** — **«Все»**.
     Это нужно, чтобы программы сотрудников могли отправлять записи без входа в Google.
     Посторонние записать ничего не смогут — без секретного ключа скрипт отклоняет запросы.
4. Нажмите **«Начать развертывание»**, затем **«Предоставить доступ»** и выберите свой аккаунт.
5. Google предупредит: **«Google не проверял это приложение»**. Это нормально для собственного
   скрипта. Нажмите **«Дополнительные настройки»** → **«Перейти на страницу … (небезопасно)»** →
   **«Разрешить»**.
6. Появится **ссылка веб-приложения** вида `https://script.google.com/macros/s/…/exec` —
   скопируйте её (кнопка «Копировать» рядом).

## Шаг 5. Завершите настройку в программе
1. Вставьте ссылку веб-приложения в поле **«Ссылка веб-приложения»** на вкладке «Статистика».
2. Включите переключатель **«Отправлять статистику в Google Таблицу»**.
3. Нажмите **«Сохранить шаблон»**, затем **«Проверить соединение»** — должно появиться
   «Соединение есть: таблица «Статистика КП»».
4. Впишите своё имя в блоке **«Этот компьютер»** и нажмите **«Сохранить имя»**.

Готово. Сформируйте КП — через несколько секунд в таблице появятся листы «Сводка» и лист с вашим именем.

## Как подключить сотрудников
1. На своём компьютере: **⚙ Настройки → Шаблон КП → Прочее → «Экспорт настроек…»**.
2. Отправьте файл `.pbsettings` сотруднику (в WhatsApp — как «Документ»).
3. Сотрудник открывает файл двойным щелчком (или «Импорт настроек») и при запуске программы
   вписывает своё имя. Ссылка и ключ приходят в файле — вводить их не нужно.

## Если что-то не работает
- **«Неверный ключ»** — ключ в программе и в коде скрипта не совпадают. Нажмите
  «Скопировать код скрипта», вставьте код в редактор заново (Ctrl+A, Ctrl+V, Ctrl+S), затем
  **«Начать развертывание» → «Управление развертываниями» → карандаш → Версия: «Новая версия» →
  «Начать развертывание»**. Ссылка веб-приложения при этом не меняется.
- **«Google ответил не так, как ожидалось»** — проверьте, что при развертывании выбран доступ «Все».
- **Нет интернета** — записи не теряются: они копятся на компьютере и отправятся позже
  (при следующем КП, при запуске программы или кнопкой «Отправить сейчас»).
- **Нужно сменить ключ** (например, файл настроек попал к постороннему) — нажмите «Создать ключ»,
  обновите код скрипта, как описано выше, сохраните шаблон и заново разошлите файл настроек.
