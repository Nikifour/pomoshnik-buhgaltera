Версия 1.2.1

Новое:
- Индикатор «идёт работа» при чтении счёта и создании КП («Читаю счёт…», «Создаю КП…», «Сохраняю PDF…») — окно больше не выглядит зависшим.
- PDF и предпросмотр в конструкторе работают не только через Microsoft Excel, но и через LibreOffice или Apache OpenOffice, если Excel не установлен.
- Настройка «Программа для PDF и предпросмотра» (Настройки → Шаблон КП → Прочее): автоматически или принудительно Excel / LibreOffice / OpenOffice. Действует только на этом компьютере.
- Старые счета .xls читаются без офисной программы.
