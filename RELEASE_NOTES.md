Версия 1.2.2

Исправления для компьютеров без рабочего Excel:
- Если программа для PDF не справилась (например, Excel установлен, но не активирован), автоматически используется следующая: LibreOffice или Apache OpenOffice. Неработающий Excel больше не вызывается до перезапуска программы; зависший Excel закрывается.
- Apache OpenOffice: исправлена ошибка «No module named uno»; файлы с русскими буквами в имени и пути теперь обрабатываются корректно.
- Понятные сообщения об ошибках вместо кодов; при сбое OpenOffice в сообщении видна причина.
